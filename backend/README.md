# Backend Services & ML Inference Engine

This directory contains backend services, real-time transaction streaming pipelines, and ML models for the AI Banking Anomaly Detection & Explainable Risk Analysis System.

### Planned Components
- **API Engine**: FastAPI / Python asynchronous REST & WebSocket streaming server.
- **ML Models**: Variational Autoencoders (VAE), Graph Neural Networks (GraphSAGE GNN), XGBoost, and Isolation Forest.
- **XAI Engine**: TreeSHAP & LIME real-time feature attribution calculator.
- **Data Ingestion**: Kafka consumer & Redis feature store connectors.
